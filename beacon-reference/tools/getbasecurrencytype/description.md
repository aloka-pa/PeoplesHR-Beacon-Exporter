# getBaseCurrencyType

**Task:** Fetching Base Currency Details

**Tags:** EIMAdmin, NexusInformation

**Status:** live

## Description

Returns the top (first) row from the Currency Type summary grid (Code / Currency / Symbol) after clicking Show All. No record open. Exchange rate is always returned as "1".

## Signature

```
getBaseCurrencyType
```
