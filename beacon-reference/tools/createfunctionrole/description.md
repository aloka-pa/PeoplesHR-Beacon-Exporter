# createFunctionRole

**Task:** create Function Role

**Status:** unlive

## Description

In this tool, to create a functional role, if the user provides a function name, fetch the corresponding value using the functionTypes API. Then, display all available functional types, allow the user to select one, and use the corresponding value for the creation process.

## Signature

```
createFunctionRole
```

## Arguments

_None._


## Advanced arguments

- `ctl00_body_dpcountry` (string, required) — Selected functional role ID or country code. if the user give the function name correspondong value wiil be take for functionTypes Api. and display the all functionalTypes pick one and corresponding value will be take.
- `ctl00_body_txtName` (string, required) — The name or label for the functional role.
