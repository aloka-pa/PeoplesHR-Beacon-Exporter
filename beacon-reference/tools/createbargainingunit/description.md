# createBargainingUnit

**Task:** Create Bargaining Unit

**Status:** unlive

## Description

To create the Bargaining Unit, if any optional fields are left empty by the user, the process will still proceed using only the available input.

## Signature

```
createBargainingUnit
```

## Arguments

_None._


## Advanced arguments

- `ctl00_body_txtBGNName` (string, required) — Name of the bargaining unit.
- `ctl00_body_txtAbbreviation` (string, optional) — Abbreviation of the bargaining unit name.
- `ctl00_body_txtRegDate` (string, optional) — Date when the bargaining unit was registered. data format '05/01/2025'
- `ctl00_body_txtRegNumber` (integer, optional) — Registration number of the bargaining unit.only numbers access string not access
- `ctl00_body_txtRegBody` (string, optional) — Name of the body with which the bargaining unit is registered.
