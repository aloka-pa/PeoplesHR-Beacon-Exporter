# traininingDevCreateCourseDescFilling

**Task:** Generating Course Description

**Tags:** Training&Development, CreateCourses, WorkFlow, DescFilling, phase2

**Status:** live

## Description

The AI tool assists administrators in creating comprehensive course descriptions for training programs by gathering key information through guided questions. It collects details such as course topic, target audience, duration, learning objectives, and training mode, then generates a well-structured, number of characters < 250, professional course description. The generated description is automatically populated into the "Description & Target Group" field, allowing admins to review, edit if needed, and proceed with course creation.

If user asked to refine / format further, the tool must generate a new one upon request and should ask the user 'Shall I fill this description?'

## Signature

```
traininingDevCreateCourseDescFilling
```

## Arguments

_None._


## Advanced arguments

- `description` (string, required) — The finalized, rephrased course description that will be auto-filled into the Description & Target Group field
