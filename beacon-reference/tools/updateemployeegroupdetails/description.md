# updateEmployeeGroupDetails

**Task:** Update Employee Group Details

**Tags:** EIM, Headers

**Status:** live

## Description

In this tool, begin by executing the "getEIMAttributeList" API to retrieve existing data. Then, compare the updated employe group name with the previous name from the  getEIMAttributeList  response before proceeding with the update.

## Signature

```
updateEmployeeGroupDetails
```

## Arguments

- `empGroupName` (string, required) — to give the employee group Name or description.


## Advanced arguments

_None._
