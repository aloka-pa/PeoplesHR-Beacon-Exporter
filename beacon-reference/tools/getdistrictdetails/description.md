# getDistrictDetails

**Task:** Fetching The District Details

**Tags:** EIM, Headers

**Status:** live

## Description

in this tool generate the district name and value. and you get the district details get for country name corresponding value will be take and another get for province name corresponding value will be take. Before calling in this api. first execute for "getProvinceCodeDetails" tool to get the Province code.

## Signature

```
getDistrictDetails
```

## Arguments

- `countryCode` (string, required) — to get country name corresponding value will be take example code "000001".
- `provinceCode` (string, required) — to get province name corresponding value will be take example code "000001".
- `countryName` (string, required) — to get country name for user prompt.


## Advanced arguments

_None._
