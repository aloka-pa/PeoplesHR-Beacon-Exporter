# criticalIncidentJournalDescFilling

**Tags:** Performance, Critical Incident Journal, phase2

**Status:** live

## Description

The AI tool assists users in creating critical incident journal entries by guiding them through context-specific questions, automatically generating a clear and structured summary of the incident, and enabling the user to review, edit, and confirm the content before it is saved.

## Signature

```
criticalIncidentJournalDescFilling
```

## Arguments

_None._


## Advanced arguments

- `desc` (string, optional) — This is the finalized rephrased description that will be used in the critical incident journal entry
