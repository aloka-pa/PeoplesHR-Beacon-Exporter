# updateFunctionDetails

**Task:** Update Function Details

**Tags:** EIM, Headers

**Status:** live

## Description

In this tool, begin by executing the "getEIMAttributeList" API to retrieve existing data. Then, compare the updated function name with the previous name from the  getEIMAttributeList  response before proceeding with the update.

## Signature

```
updateFunctionDetails
```

## Arguments

- `functionName` (string, required) — to give the function name or description.


## Advanced arguments

_None._
