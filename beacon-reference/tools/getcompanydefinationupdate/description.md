# getCompanyDefinationUpdate

**Task:** Update Company Defination

**Tags:** EIM, Headers

**Status:** live

## Description

This tool is used to update the company definitions. When a user updates a level name, the corresponding ID is fetched data for this getCompanyDefinatio tool and passed as an argument.

## Signature

```
getCompanyDefinationUpdate
```

## Arguments

- `id` (string, required) — to get the ID for getCompanyDefination tool.
- `updateName` (string, required) — what you want update name to give the user prompt.


## Advanced arguments

_None._
