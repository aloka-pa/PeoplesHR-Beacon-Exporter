# createJobDescriptionType

**Task:** Create Job Description Type

**Status:** unlive

## Description

in this tool create Job Description Type. first execute the getJdCategory tool to get the job Category Details then display the all category details and select one corresponding value will be take.

## Signature

```
createJobDescriptionType
```

## Arguments

- `jobDescriptionTypeName` (string, required) — to give the  Job Description Type Name then will be create the Job Description Type
- `jobDescriptionCategory` (string, required) — to create job Description Category display the all job Description Category then select one corresponding value will be take. data available for getJdCategory Api . Example:-"000001"


## Advanced arguments

_None._
