# createExtraCurricularActivityCategory

**Task:** Creating New Extra Curricular Activity Category Record

**Tags:** EIMAdmin, ExtraCurricularActivities

**Status:** live

## Description

Creates a new extracurricular activity category in the system.

## Signature

```
createExtraCurricularActivityCategory
```

## Arguments

- `categoryName` (string, required) — The name of the extra-curricular activity category to create (e.g., "Sports", "Arts", "Music"). Maximum 120 characters.


## Advanced arguments

_None._
