# editExtraCurricularActivityCategory

**Task:** Editing Extra Curricular Activity Category Details

**Tags:** EIMAdmin, ExtraCurricularActivities

**Status:** live

## Description

Updates the name of an existing extra curricular activity category in the system.

## Signature

```
editExtraCurricularActivityCategory
```

## Arguments

- `categoryCode` (string, optional) — The unique code identifier for the category to update (e.g., "000001")
- `categoryName` (string, optional) — The current name of the category to update (e.g., "Arts / Creative"); optional
- `newCategoryName` (string, required) — The new name for the category (e.g., "Arts / Creative update")


## Advanced arguments

_None._
