# getTitle

**Task:** Corporate Details

**Tags:** EIM, Headers

**Status:** live

## Description

This tool is used to generate Corporate title Details. First, first executes for "gradeDetails" API to retrieve all available salary grades. Once the salary grades are displayed, the user must select one, and the corresponding value will be used for further processing. then after final execute for "createEIMModuleList" tool.

## Signature

```
getTitle
```

## Arguments

- `salaryGradeValue` (string, required) — to salary grade value to get for gradeDetails api. then available all salary grades then pick one grade corresponding value will be take.


## Advanced arguments
