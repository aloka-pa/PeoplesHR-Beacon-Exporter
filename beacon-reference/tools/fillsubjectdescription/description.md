# fillSubjectDescription

**Task:** filling the subject description

**Status:** live

## Description

fillSubjectDescription only need 4  lines context, do NOT ask the user for description, Create one based on the existing description, if empty create one using the subject. Always display the updated description and ask for consent from user before filling.

## Signature

```
fillSubjectDescription
```

## Arguments

- `description` (string, required) — Generate the subject description and limit is 2000 characters  


## Advanced arguments

_None._
