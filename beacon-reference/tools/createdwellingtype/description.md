# createDwellingType

**Task:** Creating New Dwelling Type Record

**Tags:** EIMAdmin, CensusInformation

**Status:** live

## Description

Creates a new Dwelling Type record with a specified name.
Note: users can create records with the same name.

## Signature

```
createDwellingType
```

## Arguments

- `dwellingType` (string, required) — The name of the dwelling type to create (e.g., "Temporary Shelter", "Condominium", "Villa")


## Advanced arguments

_None._
