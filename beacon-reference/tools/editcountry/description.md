# editCountry

**Task:** Editing Country Details

**Tags:** EIMAdmin, GeographicalLocations

**Status:** live

## Description

Edit an existing country record. Only change the record that the user asked to edit. Do not change any other record.

## Signature

```
editCountry
```

## Arguments

- `countryCode` (string, optional) — the country code to search for
- `countryName` (string, optional) — updated country name
- `isBase` (string, optional) — Updated base country flag ("true"/"false" or "yes"/"no")


## Advanced arguments

_None._
