# getSetupConfigurationDetails

**Task:** Setup Configuration Details

**Tags:** EIM, Headers

**Status:** live

## Description

In this tool, the Setup Configuration details are generated by retrieving the necessary data from the SetupConfiguration API. To proceed, the system first fetches the available SectionCode and ProfileCode. The corresponding Section Names and Profile Names are then displayed to the user. The user is required to select both a Section Name and a Profile Name, and based on their selection, the tool automatically picks the corresponding codes. These selected codes are then used for further configuration and setup. before to get the profile and session.

## Signature

```
getSetupConfigurationDetails
```

## Arguments

- `sessionCode` (string, required) — to get the session code for setupConfiguration api fetch to display all sessions name corresponding code you can take. Example:"1"
- `profileCode` (string, required) — to get the profile code for setupConfiguration api fetch to display all profile name corresponding code you can take. Example:"1"


## Advanced arguments

_None._
