# createStatutoryItems

**Task:** Creating New Statutory Item Record

**Tags:** EIMAdmin, CensusInformation

**Status:** live

## Description

Creates a new Statutory Item record with a specified name.

## Signature

```
createStatutoryItems
```

## Arguments

- `statutoryName` (string, required) — The name of the statutory item to create (e.g., "Provident Fund", "Insurance", "Tax Deduction")


## Advanced arguments

_None._
