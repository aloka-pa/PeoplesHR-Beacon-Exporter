# getLabourCardDetails

**Task:** Fetching The Labour Card Details

**Tags:** EmployeeInformation, Headers

**Status:** live

## Description

This tool returns Labour Card details. When a user submits a query related to Labour Card information, the first tool should be executed for "getLabourCardDetails" tool. then after check details.It provides specific details such as WPS ID No, Employee Number, Employee Name, Company/Sponsor, Occupation/Designation, Labour Card Issue Date, Labour Card Validity, and Work Permit No, among others. If the query is to check the availability of specific information, the tool should return the relevant data if available; otherwise, it should return a message indicating that no data was found. Unrelated or irrelevant details should not be displayed. and employee id means employee name.
