# updateClassificationsDetails

**Task:** Update Classifications Details

**Tags:** EIM, Headers

**Status:** live

## Description

In this tool, begin by executing the getEIMAttributeList API to retrieve existing data. Then, compare the updated classification name with the previous name from the  getEIMAttributeList  response before proceeding with the update.

## Signature

```
updateClassificationsDetails
```

## Arguments

- `classificationName` (string, required) — to give the classification Name or description.


## Advanced arguments

_None._
