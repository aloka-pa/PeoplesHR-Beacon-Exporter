# getTrainingBudgetUtilization

**Task:** Fetching Training Budget Utilization Details

**Tags:** T&D, phase2

**Status:** live

## Description

Retrieves training budget utilization summaries showing how allocated budgets are being used across training schedules, including scheduled courses, employee enrollments, and remaining budget availability.

## Signature

```
getTrainingBudgetUtilization
```

## Arguments

- `year` (string, optional) — The financial year to retrieve utilization for. Use empty string \"\" for the current active year, or specify a year like \"2025\", \"2024\", etc.


## Advanced arguments

_None._
