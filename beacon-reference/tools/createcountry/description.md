# createCountry

**Task:** Creating New Country Record

**Tags:** EIMAdmin, GeographicalLocations

**Status:** live

## Description

create a new country record

## Signature

```
createCountry
```

## Arguments

- `countryName` (string, required) — Name of the country to be created
- `isBase` (string, required) — Indicates whether this country is a Base Country (accepts "true/false". "yes/no"


## Advanced arguments

_None._
