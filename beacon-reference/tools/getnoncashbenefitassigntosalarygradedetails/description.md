# getNonCashBenefitAssignToSalaryGradeDetails

**Task:** Non CashBenefitAssign To SalaryGradeDetails

**Tags:** EIM, Headers

**Status:** live

## Description

To generate the non Cash Benefit Assignment for Salary Grade details, first fetch the salary grades using the gradeDetails API. Display all available salary grades, and upon selecting one, use its corresponding value as the argument for salaryGradeCode. dont display the edit Id and identifier only using that edit id user update refer to use.

## Signature

```
getNonCashBenefitAssignToSalaryGradeDetails
```

## Arguments

- `salaryGradeCode` (string, required) — to get the salaryGradeCode for gradeDetails api corresponding value will be take.
