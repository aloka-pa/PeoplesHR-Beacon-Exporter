# personalGradeAndGroupLevelDetails

**Task:** Fetching The Personal Grade Details

**Tags:** EmployeeInformation, Headers

**Status:** live

## Description

This tool is used to generate Personal Grade and Group Level details. It first displays all available personal grade and group level options. Once the user makes a selection, the "positionTitleDetails" tool is then executed to fetch the corresponding position titles.

## Signature

```
personalGradeAndGroupLevelDetails
```

## Arguments

- `id` (string, required) — to give the employee id Example:- "000001" etc...
