# GetCopilotSessions

**Status:** live

## Description

Fetches a list of Copilot chat sessions for a given user from Beacon's Copilot API. Supports pagination limit and filtering out Run Agent API sessions. Use this to retrieve recent session history for a user.

## Signature

```
GetCopilotSessions
```

## Arguments

- `userId` (string, optional) — userId
- `limit` (string, optional) — limit
- `includeRunAgentApiSessions` (string, optional) — includeRunAgentApiSessions


## Advanced arguments

_None._
