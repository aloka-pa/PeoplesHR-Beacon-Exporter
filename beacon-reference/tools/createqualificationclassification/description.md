# createQualificationClassification

**Task:** Creating New Qualification Classification Record

**Tags:** EIMAdmin, QualificationInformation

**Status:** live

## Description

create a new qualification classification record

## Signature

```
createQualificationClassification
```

## Arguments

- `classificationName` (string, required) — new qualification classification's name
- `rank` (string, required) — A numeric value that defines the ordering or priority of the qualification classification. Each classification must have a unique rank. 
If the user-provided rank already exists, the user must be prompted to enter a different numeric rank.


## Advanced arguments

_None._
